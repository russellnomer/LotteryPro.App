### The Problem with Task #11: The StoreKit 1 Trap
The Replit agent specified using Apple's `/verifyReceipt` endpoint. **Apple has officially deprecated this endpoint.** If you build a new app relying on StoreKit 1 and `/verifyReceipt` today, you are building on a dying foundation, and it will eventually break (or trigger review flags). All modern iOS apps must use **StoreKit 2 and the App Store Server API**. 

Instead of writing raw fetch requests, your Node backend needs to use Apple's official `@apple/app-store-server-library` to securely decode the transaction using a `.p8` private key.

### The Problem with Task #10: The Asset Generation Trap
The Replit agent suggested using `sharp` or `canvas` to manually resize images and write the `Contents.json` file for Xcode on a Linux file system. This is incredibly error-prone and a fast track to a corrupted iOS build. The Capacitor ecosystem has an official tool for this called `@capacitor/assets`. You provide one master icon, and the library automatically handles all the complex Xcode directory mapping.
